# Design: Chaves

**Status:** vigente
**Data:** 2026-11-25
**ADR:** [Chave de serviço emitida pelo admin](https://wmreis-labs.github.io/wmreis-docs/mudancas/adr/2026-11-25-chave-de-servico/)
**Tarefa:** [admin #87](https://github.com/wmreis-labs/admin/issues/87)

## Objetivo

O operador emite uma chave para um sistema chamar a API de uma empresa. A tela mostra o que a API devolve. O segredo aparece uma vez.

## Onde entra

| Rota | Quem entra | O que mostra |
| --- | --- | --- |
| `/chaves` | `OperadorPlataforma` e `Administracao` | A lista de chaves da plataforma |

O item **Chaves** fica no menu Administração, junto de Tenants. `Caixa` e `Identidade` não veem o item. Se abrirem a URL, voltam para a primeira tela que podem ver.

## Lista

Estado vazio: "Nenhuma chave de serviço." Cada linha mostra nome, empresa, acessos marcados, situação (Ligada ou Revogada) e a data de criação. Não mostra o segredo. Recarregar a página não traz o segredo.

## Nova chave

Drawer no padrão das outras telas:

- Nome, obrigatório, até 80 caracteres.
- Empresa, obrigatória, na lista de tenants que a tela de Tenants já usa. Uma chave, uma empresa.
- Acessos, caixas de `GET /admin/service-keys/catalog`. Nesta entrega a lista tem **Agenda do imóvel**. Sem nenhum acesso marcado, Salvar não envia.

Ao salvar com sucesso, um diálogo mostra o segredo uma vez, com botão Copiar e o texto "Esta chave não será mostrada de novo." Fechar o diálogo volta para a lista.

## Revogar e trocar acessos

Revogar pede confirmação. A linha fica Revogada. Não há religar. Outra chave é uma criação nova.

Trocar os acessos de uma chave ligada é permitido: o mesmo id, a mesma chave, outra lista. Chave revogada não oferece essa troca.

## Estados

- **Lista vazia.** O texto diz que não há chave.
- **Erro.** A mensagem da API fica na tela.
- **Sucesso.** A criação abre o diálogo do segredo. Revogar e trocar acessos confirmam na lista.

## Fora deste desenho

A tela de Acessos continua para pessoa. Esta página não edita o segredo, não o mostra de novo e não cria chave com escrita.
