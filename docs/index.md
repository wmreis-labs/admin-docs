# Admin

Console que consome as APIs do airtestto. Login em `https://admin.testto.com.br/login` e `https://dev-admin.testto.com.br/login`. O menu de hoje é uma lista única. A proposta de separar Administração e Caixa está em [Casca](mudancas/design/2026-10-18-casca-do-admin.md).

O manual deste produto fica neste site. Demanda que também altera o airtestto fica em [wmreis-docs](https://wmreis-labs.github.io/wmreis-docs/mudancas/). O manual do serviço fica em [airtestto-docs](https://wmreis-labs.github.io/airtestto-docs/).

## Desenvolvimento

```bash
npm install
npm start
npm test
npm run build
```

O módulo de caixa está em [Caixa](mudancas/design/2026-09-27-caixa-admin.md).
